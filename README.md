# cafe-landing

가상의 카페 "모닝빈"을 소개하는 간단한 정적 랜딩 페이지입니다. 별도의 빌드 과정 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (메뉴, 소개, 오시는 길 섹션) |
| `style.css` | 페이지 스타일 (반응형 카드 레이아웃 포함) |

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.

## 참고

- 카페 이름, 메뉴, 주소, 전화번호는 모두 예시입니다.
- AI 에이전트 수업 실습용으로 제작했습니다.
